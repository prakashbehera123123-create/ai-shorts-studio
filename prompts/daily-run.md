# Daily run prompt

Run `/produce-daily-shorts`.
Use the last 7 days for news and include evergreen explainers only if they are clearly labelled.
Find 8–12 candidates, score them, and produce at most two distinct Shorts.
Use primary sources. If current web research is unavailable, stop and report the limitation.
Select English or Hinglish separately for each video; do not mix languages within one video.
Use local tools only. If TTS is unavailable, prepare voiceover scripts and stop for manual recording.
Render drafts, run QA, and stop at READY_FOR_HUMAN_REVIEW.
Do not upload, schedule, or publish anything.
