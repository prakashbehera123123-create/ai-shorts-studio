description: Review a produced Short for editorial, factual, rights and technical quality.
---

Inspect the selected production folder. Read script, sources, storyboard, asset manifest, metadata, QA output and sampled frames/audio if available. Use ffprobe for technical metadata. Report blockers before warnings. Verify all claims map to sources and every external asset has a rights/source record. Do not publish or change public platforms. Set status to READY_FOR_HUMAN_REVIEW only if all blockers are resolved.
