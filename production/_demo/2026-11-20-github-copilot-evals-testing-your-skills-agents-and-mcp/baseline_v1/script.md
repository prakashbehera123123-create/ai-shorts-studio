# Script: GitHub Copilot Evals: testing your skills, agents and MCP tools

Language: English
Target duration: 48s

## Hook
GitHub just added a way to test your Copilot skills and MCP tools.

## Narration
AI output can change from one run to the next. So one good answer does not prove your skill, agent or MCP tool works.
That is why evals exist. An eval is a repeatable test for AI behavior. You give an agent a realistic task, describe what a good result looks like, and check the result and how the agent got there.
In Copilot Evals, you ask Copilot in your own words, or use the slash eval command. You approve each run, then see which checks passed and failed.
Change your skill, rerun the same eval, and compare before and after. It is in public preview, for Individual, Business and Enterprise plans.

## On-screen text
- One good answer isn't proof
- Eval = repeatable AI test
- Task, then good result, then checks
- Ask Copilot, or use /eval

- Rerun after you change a skill
- Public preview
