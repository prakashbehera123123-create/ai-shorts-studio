# Visual guidelines

Canvas: 1080x1920 (9:16). Keep important text inside central safe area.
Style: modern, high-contrast, clean technical editorial design. Avoid clutter.
Scene rhythm: visual change every 2–4 seconds where useful, not arbitrary motion.
Captions: 1–2 short lines, large mobile-readable text, strong contrast.
Visual hierarchy: one focal point per scene. Use simple diagrams for architecture concepts.
B-roll: relevant, licensed, and logged in the asset manifest.
Charts: label axes, units, source and time range. Never fabricate data.
Screenshots: capture only public/demo data; blur personal identifiers and credentials.
Avoid: tiny UI screenshots, decorative code that is not executable, random stock footage, fake product interfaces.
